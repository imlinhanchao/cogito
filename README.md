# Haide UI Template

一个基于 Vue 3 + TypeScript + Vite 的前端开发模板，集成了 Vue Router、Pinia、UnoCSS 和 daisyUI，并采用 Header / Content / Footer 的 layout 架构。

## 技术栈

- Vue 3
- TypeScript
- Vite
- Vue Router
- Pinia
- UnoCSS
- Tailwind CSS v4 + daisyUI

## 启动

```bash
npm install
npm run dev
```

## 构建

```bash
npm run build
```

## 说明

- 布局入口在 `src/layouts/MainLayout.vue`
- 路由配置在 `src/router/index.ts`
- 全局主题状态在 `src/stores/app.ts`
- 全局样式在 `src/styles/main.css`
