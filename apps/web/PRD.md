## 互动故事引擎

### 1. 核心目标

编写一个引擎，能够**运行和编辑**基于 Twine Harlowe 语法的互动故事，支持导出独立可玩的 HTML 文件与直接运行。

### 2. 支持的 Harlowe 语法

#### 2.1 变量与赋值

- 变量以 `$` 开头：`$health`、`$name`
- 赋值：`(set: $health to 10)`、`(set: $name to "小明")`
- 数值运算：`(set: $score to $score + 1)`
- 字符串连接：`(set: $msg to $a + $b)`

#### 2.2 条件分支

- `(if: $health > 5)[你很强壮]`
- `(if: $hasKey)[门开了](else:)[门锁着]`
- 支持比较符：`>` `<` `>=` `<=` `is` `is not` `eq` `ne`

#### 2.3 链接与跳转

- 快捷链接（最常用）：`[[去森林|Forest]]` 或 `[[去森林]]`（跳转到同名段落）
- 带条件的链接：`(link:"点击我")[(goto:"NextPassage")]`
- 链接中执行操作：`[[开门|Hall]](set: $doorOpen to true)`

#### 2.4 嵌入与显示

- `(display:"Intro")` — 把另一段落的内容嵌入当前位置
- `(print: $health)` — 直接显示变量值

#### 2.5 文本样式

- `''粗体''`
- `//斜体//`
- `~~删除线~~`
- `^^上标^^`
- `,,下标,,`

#### 2.6 特殊变量（只读）

- `$passage` — 当前段落名称
- `$storyTitle` — 故事标题

### 2.7 样式

- 支持自定义 CSS 样式，允许作者在段落中嵌入 `<style>` 标签。
- 支持使用 HTML 内容标签，如 `<b>`、`<i>`、`<u>`、`<a>` 等。
- 标签可以包含 id、class、style、title 等不会造成安全问题的属性。

### 3. 用户界面

#### 播放模式（玩家视角）

- 中央大区域展示当前段落渲染后的 HTML。
- 所有 `[[链接]]` 和 `(link:)` 按钮可点击，点击后切换段落。
- 右上角可折叠的**变量面板**，实时显示所有 `$` 变量的值。
- 底部提供 **「后退」** 按钮（类似浏览器的回退，记录历史栈）。
- 提供 **「存档 / 读档」**（localStorage 保存）。

#### 编辑模式（作者视角）

- 左侧列表显示所有段落名称（可增删改）。
- 右侧是文本编辑器（带 Harlowe 语法高亮，可用 CodeMirror 或简单 textarea），带语法工具栏。
- 点击「运行」按钮切换到播放模式并从当前段落开始。
- **导入**：上传故事文件。
- **导出**：生成独立的 `.html` 文件（引擎 + 数据全部打包）。

### 4. 技术架构（轻量级）

- 解析器：手写递归下降，将 Harlowe 宏转换为 AST 再执行。
- 渲染：AST 转 HTML 字符串，插入 DOM。
- 数据模型：`story.passages` 数组，每个段落有 `name`、`tags`、`content`。

### 5. 内置示例故事（用于测试）

```
段落 "Start"：
  你站在一个岔路口。
  [[往东走|East]]
  [[往西走|West]]

段落 "East"：
  你来到了东边的森林。
  (set: $score to $score + 1)
  当前分数：(print: $score)
  [[回去|Start]]

段落 "West"：
  你来到了西边的湖畔。
  (if: $score > 0)[你看到湖中有金光](else:)[湖面平静无波]
  [[回去|Start]]
```
