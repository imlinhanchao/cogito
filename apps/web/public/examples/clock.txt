老城最里头那间钟表店，招牌斜了一角，灯还亮着。明天一早拆迁队进场，这条街就算走到头了。

你舅舅姜师傅一周前在巷口被一辆车撞倒，至今没醒，躺在医院里。出事那晚他给你打过电话，声音很急，你只记住两句。一句是“抽屉里那只怀表，谁来了都别给”。另一句被街上的喇叭盖住，你当时没听清，也就没问。

你替他守这最后一夜，其实没什么可守的。满墙的钟都停了，长短针叠成一条线，齐齐指着十一点五十九，像一屋子人屏住气在等同一个时刻。只有靠里一只老座钟还在走，走一步，顿一下，气不顺，是舅舅出门前上过发条的那只。

你正要落锁，玻璃门外有人敲了两下。隔着灰蒙蒙的橱窗，一个穿旧大衣的人站在冷风里，帽子压得很低。

[[去开门|OfficerScene]]

:: OfficerScene
来人摘下帽子，是周警官。他以前管这一片的治安，退了休又回所里帮忙。他没坐下，先扫了一眼满墙的钟，目光在那排叠成一条线的指针上停了停。

“你舅舅的东西，我一样没动。”你说。

“我知道。”他把一页纸放在柜台上，“这店明天拆，我今晚来，想请你帮个忙。”

那页纸是一份旧案底。十四年前，也是这条街口，十一点五十九分，一辆车撞倒一个夜归的男人。人叫贺远山，没救过来。车是辆厂里的公车，次日一早被人发现弃在城外，车主报了失窃，案子一直挂着。

“贺远山的女儿上个月到所里报过案，这案子又翻出来了。”周警官看着你，“你舅舅这个人，表修得好，谎说得不好。当年我问他看见什么，他说天黑，没看清。”

“您信他？”

“他前阵子自己来找过我，说有些放了多年的东西，想找个时候交出来。话没说完，人就出了事。”周警官顿了一下，“他这回被撞，也是这个钟点，也是这条街口。我怀疑这两起，是同一个人。”

门外风灌进来。他把一张名片按在柜台角上：“你舅舅要是收过一只白铜壳的怀表，你千万别动它，也别给任何人。我回所里调老档案，十一点半前尽量回来。有人来问表，你打这上面的电话。”

他走到门口又回头：“你舅舅那晚给你打电话，想必交代过什么。他让你别给谁，你就别给谁。”

门合上。那页旧案底还摊在柜台上，贺远山的名字旁边印着一行时间，十一点五十九分。

:: ManKnock
十一点刚过，一辆黑色轿车停在街对面，没熄火。车里下来一个男人，五十多岁，大衣笔挺，笑呵呵地推门进来，带进一阵冷风和淡淡的古龙水味。驾驶座上那个司机没下车，留着寸头，隔着玻璃盯着这边。

“小姜师傅吧？”男人熟门熟路地环顾满墙的钟，“我是你舅舅的老朋友，姓沈。老姜这一躺下，好些事得有人替他拿主意，我就先来了。”

他从怀里摸出一叠钱，搁在柜台上。“他搁你店里寄存的东西，说好拆迁前要取走。一只怀表。你也清楚，老姜这店，有些货从不打票，不记账。”

他说话时，目光往墙上的钟瞟了一眼。“十一点五十，我再回来取。这中间你慢慢想，不急。”

:: ManTest
“沈老板认得那表，那您说说，背面刻了什么？”

他笑了一下，答得顺溜：“一只旧怀表能刻什么。我当年搁老姜这儿修的，也不是什么值钱的物件。”

他答不上来。一个专程赶来取表的人，答不上来自己那只表背面刻着什么。贺兰答那两句时，声音发着抖，却一个字都没错。你心里有了数。

他像是看出你脸色不对，笑容收了一点：“怎么，表不在了？”

“表的事，我得问过舅舅才能做主。”

“你舅舅一时半会儿醒不了。”他把那叠钱又往前推了推，“年轻人，有些事知道得少，睡得着。十一点五十我再来。”

他起身，走到门口又回头：“那表是老姜当年答应给我的。你拦得住我，拦不住你舅舅那声答应。”

门在他身后合上。最后那句话比那叠钱更让你心头发沉。他要是真应过舅舅什么，舅舅那半句话里，怎么一句都没提他。

:: ManRefuse
